# Analysis of Red and White Wine Samples from Portugal
A project for Computational Intelligence course, where a data analysis was done using a dataset of wines to demonstrate the main foundations and visualization of the elements provided and their characteristics. Therefore, unconditional monovariate, conditional class monovariate, unconditional bivariate and unconditional multivariate analyses were used to obtain insights into how the type of wine, white wine and red wine, may have differences in relation to their predictors and how this affects the wine's property.
